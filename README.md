# RLO Telemetry

Dashboard de análisis y telemetría de Fórmula 1 (FastF1 + Dash), en español.
Tema oscuro estilo broadcast, datos pre-computados para carga instantánea,
clasificación oficial, telemetría y timing en vivo.

- Hecho por [@redlightsoff5](https://instagram.com/redlightsoff5)
- Desplegado en Hugging Face Spaces (Docker, 16 GB RAM) para soportar la
  carga de telemetría de FastF1 sin quedarse sin memoria.
